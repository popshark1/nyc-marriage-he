# אתר סטטי – אינדקס הנישואים של ניו יורק

התיקייה הזו היא אתר שלם, בלי שרת ובלי מסד נתונים. החיפוש רץ כולו בדפדפן:
המאגר (4.75 מיליון רשומות) מפוצל לקבצים דחוסים לפי הצליל של שם המשפחה ולפי השם הפרטי.
שמות נפוצים מאוד מפוצלים גם לפי עשור. כל חיפוש מוריד רק את הקבצים הדרושים לו
(בדרך כלל 1–20, לכל היותר 40). גודל כולל: כ־370MB, כ־10,500 קבצים.

## שפות
הממשק זמין בעברית (ברירת מחדל), אנגלית, יידיש, צרפתית ורוסית. מחליפים שפה בכפתורים שבראש העמוד, והבחירה נשמרת.
אפשר גם לקשר ישירות לשפה: `?lang=en`, ‏`?lang=yi`, ‏`?lang=fr`, ‏`?lang=ru`. התרגומים נמצאים ב־`i18n.js`.
החיפוש מקבל שמות בכתב עברי ביידיש (ליגטורות װ ײ ױ, ניקוד אַ אָ, טש ודזש) ושמות פרטיים ייִדישאיים (יאַנקל, הערשל, פֿייגע).

אפשר לחפש גם שמות בכתב קירילי. המנוע ממיר אותם לכתיב הלטיני שברשומות: ‏‎-ович‎ הופך ל־‎-OWITZ‎, ו־Г נבדקת גם כ־H (‏Горовиц → HOROWITZ). יש גם מילון שמות פרטיים רוסיים (‏Хаим → HYMAN/CHAIM).

## חיפוש
* **חיפוש חופשי** (ברירת המחדל): תיבה אחת שמקבלת שמות פרטיים ושמות משפחה, בעברית או באנגלית ובכל סדר.
  היא מזהה לבד שנה (1962), טווח (1960-1965), עשור (שנות ה-60 / 1960s), רובע (ברוקלין / Queens) ומספר רישיון (#1234).
  שני בני זוג מפרידים ב־`&` או ב־ו' לפני שם פרטי: `שרה כהן ודוד לוי`.
  המנוע בודק לכל מילה כמה רשומות יש לה כשם משפחה וכשם פרטי, ומוריד רק את המילה הממקדת ביותר.
* **חיפוש מפורט**: שדות נפרדים לכל אחד מבני הזוג. עובד גם עם שם פרטי בלבד.

## העלאה ל־Cloudflare Pages (חינם, מומלץ)
דרוש Node.js. מתוך התיקייה הזו:
```bash
npx wrangler login
npx wrangler pages deploy . --project-name nyc-marriage-he
```
האתר יעלה בכתובת `https://nyc-marriage-he.pages.dev`. דומיין משלכם מחברים בלוח הבקרה:
Workers & Pages → הפרויקט → Custom domains.
(העלאה בגרירה דרך הדפדפן לא מתאימה לכמות כזו של קבצים. צריך Wrangler.)

## העלאה ל־GitHub Pages (חינם)
```bash
git init && git add . && git commit -m "NYC marriage index"
git branch -M main
git remote add origin https://github.com/USER/nyc-marriage-he.git
git push -u origin main
```
אחר כך: Settings → Pages → Source: `main` / root. הכתובת תהיה `https://USER.github.io/nyc-marriage-he/`.

## כל אחסון סטטי אחר
Netlify, Vercel, S3, Nginx – פשוט מעלים את התיקייה כמו שהיא.
**בדיקה מקומית:** `python3 -m http.server 8000` ואז http://localhost:8000.
פתיחה ישירה של index.html מהדיסק (file://) לא תעבוד, כי הדפדפן חוסם טעינת קבצים כך.

## עדכון הנתונים
בערכה (`nycmarriage/`): `python3 build_index.py` ואז `python3 export_static.py --out <התיקייה הזו>/data`.

## הבדלים מהגרסה עם השרת
* צריך לפחות שם אחד. מספר רישיון עובד כמסנן, אבל לא לבד.
* "מתחיל ב…" וכוכבית דורשים לפחות 2 אותיות ראשונות.
* בחיפוש רחב מאוד (למשל רק "Mary") נטענים לכל היותר 40 קבצים: הכתיבים הקרובים והנפוצים ביותר. במקרה כזה מוצגת הודעה, ומספיק להוסיף שנה, רובע או שם נוסף כדי לקבל תוצאה מלאה.
* רשומות זהות לגמרי במקור (כ־1–4%) מוצגות פעם אחת.

## סטטיסטיקות

‏`stats.html` מציג ניתוח של המאגר לפי שמות: אחוז הזוגות עם שמות יהודיים בכל רובע ועשור, וכמה אנשים עם שם פרטי ישראלי מובהק התחתנו בכל שנה, לפי מוצא בן או בת הזוג. השמות הישראליים אומתו מול נתוני הלמ"ס על שמות שניתנו לתינוקות יהודים בישראל בשנים 1948–1995 (פרסום 391/2025, דרך החבילה babynamesIL), ונבדקו מול נתוני השמות של הביטוח הלאומי האמריקאי (SSA). הנתונים המחושבים נמצאים ב־`stats/data.json`. מדובר באומדן לפי שמות בלבד.

## משחקונים
`games/wedding.html`: "מחבואים בחתונה", משחק תלת־ממדי בסגנון קוביות. בוחרים לשחק בכלה או בחתן ומחפשים את בן או בת הזוג בין האורחים בגן.
מחוץ לשער הגן יש עיר משנת 1910, בסגנון הלואר איסט סייד בניו יורק (`games/city.js`). יש בה רחובות מרוצפים באבן, פנסי גז, עמודי טלגרף, בנייני לבנים עם מדרגות חירום ומגדלי מים על הגגות, וחנויות עם שלטים באנגלית וביידיש. יש גם שוק של עגלות רוכלים, חבלי כביסה מעל הרחוב, מגדל שעון ובית כנסת בקצה הרחוב הראשי. ברחובות נוסעות כרכרות סוסים, עגלת חביות וחשמלית רתומה לסוסים, והן עוצרות כשמישהו עומד לפניהן. בטקס הלילי נדלקים האורות בחלונות.
אפשר גם לשחק בתור הרב: אז החתן והכלה מתחבאים שניהם, ומי שנמצא הולך לחכות ליד החופה עד שגם השני יימצא. כשהזוג נמצא, האורות כבים וההורים של שני הצדדים מלווים אותם אל החופה.
בכל משחק בן או בת הזוג מתחילים במקום אחר, ובמהלך המשחק מתגנבים בין מחבואים במסלולים אמיתיים (A*). בקושי הגבוה הם גם בורחים כשמתקרבים. גם חלק מהאורחים מסתובבים בגן.
ברקע מתנגנת להקת כליזמר (קלרינט, אקורדיון, טובה ותוף) עם שני לחנים מקוריים בסולם פריגיש: פריילעכס ובולגר. המוזיקה מוקלטת מראש לקובץ `games/assets/klezmer.mp3`. הקלרינט מנגן כקול רציף (לגאטו), סוף הקובץ מתחבר בדיוק להתחלה, והמשחק מנגן אותו בלופ מדויק, בלי קטיעות. את הקובץ מייצרים מחדש עם `games/tools/render-music.html`, מתוך הקוד שב־`games/klezmer.js`.
הרב שמתחת לחופה נותן רמז כשניגשים אליו: ליד איזה מקום ראה את בן או בת הזוג. האורחים מדברים, מוחאים כפיים ורוקדים בקצב המוזיקה, ומלצרים עם מגשים ואורחים מסתובבים בגן.
יש בו שתי רמות קושי, ג׳ויסטיק מגע לטלפון ותמיכה בארבע השפות. כל הגרפיקה והצלילים נוצרים בקוד.
המשחק משתמש ב־three.js ‏(MIT, ‏`games/lib/three-LICENSE.txt`), ששמור בתוך האתר ולא נטען משרת חיצוני.
